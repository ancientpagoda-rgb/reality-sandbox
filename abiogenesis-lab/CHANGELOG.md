# Changelog

## 0.2.0 — prebiotic heredity

- Added matter-accounted chemistry→polymer transfer and return.
- Added generic sequence-bearing polymers with templated copying and mutation.
- Added polymer-first surface replication on mineral/wet-dry environments.
- Added amphiphile compartments that can capture polymers, grow, fail, release contents, and divide.
- Added sequence-dependent copy, catalytic, membrane, and stability traits as provisional coarse-grained priors.
- Added measured heredity, replication, variation, selection, generations, metabolism, and cell-division signals.
- Added `transient-replicator` outcome class.
- Run archives now preserve the most advanced state even when it later collapses.
- Life detection now uses local chemical hotspots rather than only planet-wide means.
- Added evolutionary heatmaps and per-cell polymer sequence inspection to the browser lab.
- Batch CLI now accepts `--columns`, `--rows`, and `--dt`.
- Expanded tests from 5 to 10.
